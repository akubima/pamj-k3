Setting NTP client

Pastikan komputer klien memakai server ini sebagai DNS agar ntp.k3.lan ter-resolve (atau ganti dengan IP server).

Jalankan PowerShell / CMD sebagai Administrator:

w32tm /config /manualpeerlist:"ntp.k3.lan" /syncfromflags:manual /reliable:no /update
net stop w32time && net start w32time
w32tm /resync /force

Verifikasi:

w32tm /query /status
w32tm /query /peers
w32tm /stripchart /computer:ntp.k3.lan /samples:5 /dataonly

Via GUI: Settings → Time & language → Date & time → Additional clocks → Internet Time → Change settings → isi ntp.k3.lan → Update now.

Install chrony lalu edit /etc/chrony/chrony.conf (Debian/Ubuntu) atau /etc/chrony.conf (RHEL/Fedora). Hapus/komentari baris pool atau server lama:

sudo apt install chrony        # Debian/Ubuntu
sudo dnf install chrony        # RHEL/Fedora
server ntp.k3.lan iburst prefer
makestep 1.0 3
sudo systemctl restart chrony    # RHEL: chronyd
chronyc sources -v
chronyc tracking
sudo chronyc makestep

Offset terlihat di baris System time pada chronyc tracking.

Edit /etc/systemd/timesyncd.conf:

[Time]
NTP=ntp.k3.lan
sudo timedatectl set-ntp true
sudo systemctl restart systemd-timesyncd
timedatectl timesync-status
timedatectl status

Cek offset sekali jalan tanpa mengubah jam:

sntp ntp.k3.lan
# atau
ntpdate -q ntp.k3.lan
